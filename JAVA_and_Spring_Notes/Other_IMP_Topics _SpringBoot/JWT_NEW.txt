## ✅ **JWT Authentication – Simple Notes**

### **Your Initial Confusion**

*   *“If we don’t store tokens on the server, how do we know the token is ours?”*
*   *“Does the JWT contain the secret key?”*
*   *“If outsiders know user details, can they generate tokens?”*

### **Final Clarification**

*   **JWT does NOT contain the secret key.**
*   The **secret key stays only on the server** (in `https://linkprotect.cudasvc.com/url?a=https%3a%2f%2fapplication.properties&c=E,1,EyIbfWTBhneDnlmEaakIZt1Hi3BFceRKeMQKp7gmRUMtAtKZYCloJJZHpTclK7-4WWf9hAlU7ketZgba66USbWiaW9Qz8Yncx-dMFc6FXJs,&typo=1` or environment variables).
*   JWT is **signed** using the secret key, not encrypted.
*   Validation works by **recomputing the signature** and comparing it with the token’s signature.

***

### ✅ **How JWT Works**

1.  **Login**
    *   User sends username/password.
    *   Server verifies credentials and generates JWT:
            Header.Payload.Signature
        *   Header: Algorithm info (e.g., HS256)
        *   Payload: User details (e.g., userId, roles)
        *   Signature: Created using `secretKey` + Header + Payload.

2.  **Send JWT to Client**
    *   Client stores token (e.g., in localStorage).

3.  **Subsequent Requests**
    *   Client sends token in `Authorization: Bearer <token>` header.

4.  **Validation**
    *   Server takes Header + Payload from token.
    *   Recomputes signature using **secret key**.
    *   If recomputed signature == token’s signature → ✅ Valid token.

***

### ✅ **Why Outsiders Cannot Forge JWT**

*   They can decode Header and Payload (Base64), but **cannot create a valid signature without your secret key**.
*   Your server rejects any token with an invalid signature.

***

### ✅ **Example in Spring Boot**

**Generate JWT:**

```java
String token = Jwts.builder()
    .setSubject(username)
    .claim("userId", user.getId())
    .setIssuedAt(new Date())
    .setExpiration(new Date(System.currentTimeMillis() + 86400000)) // 1 day
    .signWith(SignatureAlgorithm.HS256, secretKey)
    .compact();
```

**Validate JWT:**

```java
String token = request.getHeader("Authorization").substring(7);
Claims claims = Jwts.parser()
    .setSigningKey(secretKey)
    .parseClaimsJws(token)
    .getBody();

String userId = claims.get("userId", String.class);
```

***

### ✅ **Key Points**

*   Secret key is **only on the server**.
*   JWT is **stateless** → no token storage needed.
*   Use HTTPS + short expiry + optional blacklist for security.

    Token = Header + Payload + Signature

*   **Header** → Algorithm info (e.g., HS256)

        Signature = HMACSHA256( Header + Payload + secretKey )
